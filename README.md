# Selisha Thapa — Portfolio

A minimalist, typography-driven personal portfolio built with Next.js, TypeScript, Tailwind CSS, Lucide React, and Framer Motion.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

All site content lives in [`src/data/resume.ts`](src/data/resume.ts). Update that file to change name, about copy, experience, education, skills, projects, and social links — the UI maps over it automatically.

## Scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run start` — serve the production build
- `npm run lint` — run ESLint
